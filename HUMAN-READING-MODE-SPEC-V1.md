# V3.11 Human Reading Mode

## Goal
The internal engines remain active, but technical engine output is not shown to the reader.

## Visible result order
1. คำตอบจากไพ่ — answer the actual question first.
2. ไพ่กำลังบอกอะไร — one short connected explanation of all three cards.
3. สรุป — one-line takeaway.
4. ไพ่ที่เปิด — compact card names only.
5. Optional Secret Energy Card button and human-language clarifier.

## Hidden from normal UI
Question-analysis metadata, confidence score, contradiction mechanics, Hidden Pattern labels, Key Insight labels, personal-fusion block, and per-card role meanings.

## Secret card
The secret card remains optional and one-per-question. Its UI uses plain language: what it adds and how to use it, rather than engine terminology.
