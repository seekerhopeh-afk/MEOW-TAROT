# MEOW TAROT V2.1 — Desktop Large + New Reading Engine

## อัปเดตเว็บ
1. แตก ZIP
2. อัปโหลดไฟล์ทั้งหมดไปแทนไฟล์เดิมใน GitHub repo `MEOW-TAROT`
3. Commit changes
4. Vercel จะ deploy ใหม่อัตโนมัติ

ไม่ต้องตั้ง `ANTHROPIC_API_KEY` และไม่ต้องใช้โฟลเดอร์ `api/`
