# MEOW TAROT — Free Version

เวอร์ชันนี้ไม่ใช้ Anthropic API และไม่ต้องมี API Key

## Deploy บน Vercel
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub repo `MEOW-TAROT`
2. Import repo เข้า Vercel
3. Framework: Vite
4. Root Directory: `./`
5. ไม่ต้องเพิ่ม Environment Variables
6. กด Deploy

คำทำนายถูกสร้างในเบราว์เซอร์จากระบบความหมายไพ่ภายในเว็บ จึงไม่มีค่า API
